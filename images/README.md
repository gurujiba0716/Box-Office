# Image Files

Place the following files in this folder before publishing the final website:

- `hero.jpg`
- `food.jpg`
- `drinks.jpg`
- `sports.jpg`
- `music.jpg`
- `exterior.jpg`
- `map-placeholder.jpg`

Recommended image sizes:

- `hero.jpg`: 1920 x 900 or larger
- Card images: 900 x 600 or larger
- `exterior.jpg`: 1200 x 800 or larger
- `map-placeholder.jpg`: 900 x 450 or larger
