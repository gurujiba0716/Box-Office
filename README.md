# Box Office Phnom Penh Website

Static homepage for Box Office Phnom Penh, built with plain HTML, CSS, and JavaScript.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload these files and folders to the repository root:
   - `index.html`
   - `css/style.css`
   - `js/script.js`
   - `images/`
   - `.nojekyll`
3. In GitHub, open `Settings` > `Pages`.
4. Under `Build and deployment`, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Save and wait for GitHub Pages to publish the site.

## Images

Add these image files inside the `images/` folder:

- `hero.jpg`
- `food.jpg`
- `drinks.jpg`
- `sports.jpg`
- `music.jpg`
- `exterior.jpg`
- `map-placeholder.jpg`

The layout includes fallback background colors, so the page will still render while images are missing.
